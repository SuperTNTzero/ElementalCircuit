## 依赖与所有权

`domain` 仅依赖 Java 17；`adapter` 负责 JSON 与资源；`server` 负责物品/玩家持久化、法阵调度和 Minecraft 实际结算；`client` 只编辑配置副本与显示观察；`network` 验证目标后在服务器线程串行执行请求。不存在客户端伤害结算或编辑器推进 VM。

`MagicCircuit` 是不能直接实例化的抽象契约，`TickCircuit` 唯一运行核心。`Blueprint`、`Rune`、`Route`、`Packet`、`Mixture`、`SpellSpec`、`Rules` 为不可变定义或值对象。Snapshot 中所有数组拷贝隔离，Mixture 不暴露内部存储。法杖弱缓存不拥有持久状态，物品 NBT 才是来源；换槽、丢弃、保存使用同一身份与现场。

客户端包仅包含目标 UUID、动作与有界载荷。服务器要求主手仍是同一法杖；图编辑、材料安装、起阵与手动开关均在服务器线程完成。提交蓝图时服务器冻结规则优先，客户端不能更改恢复速度、注入量、半径规格或材质；材料安装独立检查布局与实际库存，然后一起应用。配置失败不修改活动法阵。

## 固定步与账本

每个服务器逻辑步先接收上步运输，读取上步信号，再按符文编号求值，最后发布运输和信号。新运输不能在同一步穿过多枚符文。线路顺序决定余数及逐出口归属；交叉不是接点。长度目前改变损耗，运输每条线至少一步，不声称已按长度计算传播时刻。

所有魔力量为 16.16 非负有界整数，逐成分分流余数按存档的线路顺序分配。纯净与八本源正反相共 17 成分。每线到达缓存、在途和待发缓存分别拥有载荷；已经分配的份额不会因另一个出口空闲而改送。兼容性、容量或与门条件失败时保留原输入。支路发布一次计损耗，阻塞重试不重复收费。

法阵账本恒等式：`累计外部供给 = 当前缓存 + 回收储备 + 累计损耗 + 累计交付`。信号成本计入供给及损耗；世界层只得到已交付的作用份额。停止后改图回收未交付成分，保留已转化的元素，不把它们变回免费纯净。后续优先注入回收量，不重复计外部供给。回收规格 64，超量拒绝重配。

持续输入到期时先检查所有输入容量，再计算全部控制成本及外部注入缺额，并由共享 ManaSource 一次原子扣费。失败停止新注入及控制求值，保留门态，残余魔力继续通过既定通路。充值不会起阵。为了首批可复现性，输入量 4、间隔 10、控制窗口 40 冻结在规则中，尚不开放逐输入独立节律编辑。

## 参数与实际效果

同维度相同修饰幂等，不同修饰冲突；合并不会覆盖请求。量控制支付，数量不足保留。显式射程按整数距离计代价，显式半径按包围格体积计代价，显式指向精度按四档额外代价降低相同支付的作用份额；最低可交付量为零时等待，不吞掉资源。未指定项使用冻结的默认值。

球状：范围时在施法者中心结算；指向时产生每步 0.75 格、有限射程的服务器弹道，命中或到达射程后产生球形作用域。光束：瞬时有限射线，只作用于首次生物接触，不沿线重复作用；地形阻断。盾牌：前置 1.5 格、寿命 60 步、容量为已交付量的 8 倍、仅正面拦截本模组球状弹道；容量不足时按成分比例吸收，超出量继续飞行。每个维度最多 256 在途弹道、64 屏障；屏障按创建顺序淘汰最早项。范围结算按 UUID 排序、等份分配成分，并进行生物中心视线遮挡查询。

元素使用原版伤害、治疗、灭火、冻结、药水和运动响应。八种本源均有响应入口；这属于游戏适配值，不是焦耳、动量、真实温度或守恒热力学。世界层位置和碰撞使用 Minecraft 原生浮点 Vec3；只有法阵资源/VM 为定点，不能声称整部 Minecraft 确定性定点模拟。散布由法杖 UUID、事件序号及精度确定，关闭粒子不改变命中。

## 材料与存储

木头/黄铜/水晶半径 4/6/8（61/127/217 格），逐格保留率 62259/64880/65405，符文两端额外耦合 65470。数值协议 v1 冻结，规则 JSON 负责其他默认成本、供给和几何参数。当前尚未把原工程材料安全负载转为 Minecraft 耐久/温度风险。

使用 Minecraft 原版 9＋27 格背包与默认 64 堆叠，不修改原版背包为原项目的 120；状态法杖不可堆叠。没有暗送材料板或设备。合成配方使模组可以在独立生存世界获得工具。

蓝图保存创建配置及冻结规则，不含库存、运行状态、收支或身份。导入到已有载体时保持服务器材料和规则。完整现场另存版本、时钟、事件序号、生命周期、计费和回收储备、逐线缓存、控制态和信号；玩家槽保存恢复等待与整数余数；世界 SavedData 保存弹道及屏障。恢复前检查完整性、数量/坐标边界和账本；错误数据不被免费新现场替换。

已卸载区块及离线暂停，不补算真实时间。原版容器不逐物品推进，放入箱子会冻结内部现场；背包中的活动法杖继续运行。掉落时停供并冻结内部残余，拾取后恢复残余流转。该边界明确区别于原项目统一对象调度目标，后续若增加容器/设备持续模拟，需单独版本化调度和卸载规则。
