# 独立法杖工作台、蓝图簿和法术书

适用 v0.10.0，Minecraft 1.20.1 / NeoForge 47.1.106。法术书本身拥有法阵，并非只记录法杖的槽位索引。

## 独立操作入口

| 入口 | 保存内容 | 操作 |
|---|---|---|
| 法阵刻印页 | 当前载体所选法阵的创建配置 | 绘制、布线、蓝图、基板与法阵互联；不再装配或修缮法杖 |
| 法杖工作台 | 物理法杖的杖端、杖身、杖尾及磨损 | 主手持杖右键方块，选择部位、预览属性、明确安装；修缮消费木质基板 |
| 蓝图簿 | 最多16页、各有名称的独立蓝图 | 右键打开目录和只读法阵预览，输入文本码新增、复制文本码、改名、删页 |
| 法术书 | 最多4个独立法阵与完整运行状态 | 右键或B查看/预览/切换；刻印入口管理书内法阵 |

法杖工作台配方：第一行中间石英；第二行铜锭、原版工作台、铜锭；第三行任意木板。蓝图簿配方为同一竖列的纸、书、木质基板；法术书为紫水晶碎片、书、木质基板。两类书不可堆叠，空白书不包含示例法阵或额外魔力。新法术书沿用载体的一块空白木基板；新增槽位需要实际基板。

## 绘制与归档

1. 主手持法术书，蹲下右键进入本书刻印页；也可主手持杖、副手持书，蹲下右键法杖进入本书刻印页。未持书时保持原法杖刻印操作。
2. 绘制并保存，或明确载入现有示例。底部“法阵管理”新增槽位、安装基板及建立书内互联；需要消耗的基板来自背包。
3. 随身携带实体蓝图簿，在刻印页右上角打开“蓝图簿”。输入页名后“保存当前草稿”，会归档实际草稿，包括尚未保存到载体的修改。
4. 目录选页显示同一套矢量符形和真实保存路线。选页可复制EC1文本码、改名、删除；删除需要再次点击该页确认。
5. “载入选页到草稿”保留当前目标的材料和冻结规则，越界或不兼容时完整拒绝。成功载入后仍需点击刻印页“保存”；蓝图页不携带身份、库存、运行现场或魔力账本。

没有进入刻印页时，右键实体簿子也能查看、命名和分享。新增页通过独立多行文本码界面输入；从刻印页打开则直接归档草稿。原底部蓝图文本导入/导出页面继续提供无需实体簿子的单次分享。

## 副手法术书施法

主手持法杖，副手持法术书：Z上一法阵、X下一法阵，B打开书的目录和法阵预览。三个动作均注册到Minecraft控制设置，可重绑。快捷栏上方显示当前阵、页数和供给状态，按键提示采用当前绑定。

右键法杖起停书中所选法阵。选页只改变启动目标，不重置实例，也不自动启动下一页；其他已启动的槽位继续独立运行，便于书内接口互联。需要单独施法时先停供原页，再换页起阵。书的目录允许先预览另一个法阵，再明确选择它。

书提供完整法阵；主手法杖提供杖端强度、施法节奏及耐久，尾部仍决定实际近战伤害。发射磨损发生在主手杖，书不会承担法杖磨损。所有法阵仍使用玩家唯一的有限魔力槽。更换另一根法杖不会复制或清空书内法阵。

副手法术书配合主手法杖时，主手杖自身的法阵停供并冻结残余，避免同时执行两套启动来源；其他背包法杖仍遵循原来的活动规则。将书移出副手、主手改持其他物品或丢出书时，书停供并冻结内部残余。重新装备不会自动起阵，也不恢复免费资源。已发射的世界弹道继续由原世界系统推进。原版箱子内物品仍不逐步模拟。

## 工作台安装

工作台采用单独的输入页面和只读部件预览渲染。先选杖端/杖身/杖尾，再选目标部件，顶部展示替换后的强度、速度、剩余耐久和近战伤害。明确点击安装才发送服务器请求。

安装消费一件实际新部件并回收旧件，保持原始磨损；杖端和杖身共同决定耐久上限，换低耐久组件可能使法杖暂时无法施法，需要修缮。修缮消费一张木质基板，减少48点磨损，满耐久拒绝扣料。法杖和副手书须全部停供。

服务端记录玩家、维度、工作台位置和原法杖身份。每次请求重新检查方块存在、区块已加载、距离不超过8格、主手仍为原杖；请求必须匹配会话的物品与位置。离开、拆除或换杖后旧请求不扣材料。原法阵网络动作6/7明确拒绝，不能绕过工作台。

## 保存与边界

法术书使用已有 `ElementalCircuit.Identity` 与程序集v1，包含每槽完整TickCircuit v3、冻结材料、控制状态、缓存、回收储备、累计收支、内部连接及在途份额。保持原法杖、固定阵和世界法术v6兼容，不迁移或自动赠送旧物品。

蓝图簿新增独立v1卷册，保存UUID、递增且不复用的页编号、当前选页、名称和创建蓝图。页名1–32个普通字符，最多16页，单页蓝图64KiB、整本JSON512KiB，超限和不合法文本在写入前拒绝。一次只把选页蓝图和目录发送给客户端；切页不会把全部16页配置反复同步。

服务器只允许修改持有的法术书或自己库存中的原蓝图簿；重复簿身份拒绝。快速切阵仅发送小型HUD状态，完整配置只在打开页面和页面刷新时同步。控制状态与资源推进完全在服务器，预览不会求值、命中或修改任何世界数据。

网络协议升级7，客户端与服务器须同时更新。损坏NBT保留原记录并拒绝使用，不自动改为空书。此版本未扩展玩家法术书动画、书架自动施法、跨载体移动书连接或多人权限插件集成。
