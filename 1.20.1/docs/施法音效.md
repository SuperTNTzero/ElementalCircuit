# 施法音效

2026-10-30 · v0.14.0 · 分支 `codex/casting-audio`

## 玩家体验

成功起阵有短促启动声；法术实际输出时有发射声；接触实体、方块、屏障和范围结算有命中反馈；屏障创建时有展开声。停止供给、拒绝起阵与没有元素的输出不会误播起动或发射声。飞行尾迹和持续屏障显示不每步叠音。

火使用短促噼啪噪声，水使用气泡调制，风使用气流，土偏低频震动，雷使用快速电流脉冲，光使用钟鸣泛音，暗使用低频颤动，奥术使用调频音色。纯净素材也预留对应资源，但现有纯净魔力不显化，因此不触发元素发射声。混合输出按当前主元素选择音色，不为每种成分堆叠多层声音。

声音使用 Minecraft 原生空间音源，24格范围内随距离衰减。到“选项 → 音乐和声音 → 玩家”调整音量，总音量同样生效；“显示字幕”显示起阵、释放、命中及屏障提示。没有新增按键。

## 静态资源与职责

- `assets/elementalcircuits/sounds/spell/`：28个原创合成短音效，24 kHz、单声道、OGG/Vorbis，总计168,015字节。最长0.68秒，不循环；提前加载避免首次施法才请求解码。
- `sounds.json`：声音事件、字幕和原生24格衰减配置。静态声音可通过资源包替换，走 Minecraft 正常资源重载。
- `audio/palette.json`：版本1的离线合成参数；`tools/bake-audio.py` 按固定种子生成波形，写出素材和解码测量报告。编码器仅为制作工具，不随模组运行。
- `audio/policy.json`：版本1的启动配置，控制范围、表现预算、音量和去重间隔；不是法阵规则或玩家存档。修改后重启；调整衰减距离时也须同步素材声明。
- `SpellSound` / `AudioPolicy` / `SoundBudget`：独立观察值和纯 Java 播放策略。`SpellSounds` 负责注册和 Minecraft 适配，不引入客户端玩法求值。

制作环境安装 `numpy scipy soundfile` 后执行 `python tools/bake-audio.py`；本机使用 `python tools/bake-audio.py --tooling build/audio-tooling`。该工具同时检查28个输出均能被Vorbis解码、单声道、长度正确、非静音且峰值低于0.95，并写出 `docs/metrics/casting-audio-assets.json`。生成的声音属于首期合成素材，尚未经过正式听感混音验收。

## 同步与预算

起动声只在成功提交起阵后观察；发射、展开和命中观察来自服务器已处理的施法与接触。声效不读取客户端粒子、不检测客户端碰撞，也不决定伤害、元素反应、魔力或寿命。实际法术继续推进时，丢弃音效不会中止玩法。

服务器在世界结算完成后发送原生 `ClientboundSoundPacket`。它属于 `PLAYERS` 分类，由声音引擎处理混音、字幕、暂停和世界退出；没有增加自定义网络协议，也没有客户端自建声道池。网络协议仍为10；两端需一起安装0.14.0以具备相同声音事件和资源。VM v4、世界法术v7、程序集v1及既有存储封装保持。

每个世界步至多接收64条声音观察，每玩家只接收范围内最近8条。同阶段、同4格空间单元内，不同元素也合并，避免混合与分裂重复堆叠。起阵／发射／命中／屏障的最短重复间隔分别为8／4／3／12个世界步；这只改变听到的声音频率。冷却记录至多保留768条，过期自动移除，世界卸载全部释放；同一步多次排空也不能重置接收预算。世界步结束后到达的起阵命令保留到下一次统一发布，下一步的新观察不会覆盖它。音高在0.96–1.04之间轻微变化，不使用玩法随机数。

这是声音观察的发送限制；不承诺将多个原生声音事件编码成单包，也不代表做过多人服务器带宽验收。当前仍为短音效，没有持续吟唱、跟随弹体的循环声或独立施法音量滑块。

## 验证

最终结果、日志与构建哈希见 [验证记录](验证记录.md) 和 `docs/metrics/casting-audio.json`。

- 纯 Java 检查覆盖空间合并、固定步冷却、范围筛选、按玩家限制、同一步重复排空、命令跨世界步保留、长时间记录边界、时钟切换、静态资源覆盖及法阵现场不变。
- Minecraft GameTest覆盖28个声音事件的原生网络编解码，真实起阵／停供／失败起阵与纯净输出的音效语义，屏障不逐步重播，方块接触，以及声音队列饱和时的伤害和弹道保存一致性。
- `runClient -PaudioSmoke=true` 使用 `build/audio-world-smoke/` 隔离世界。游戏真实Vorbis解码全部28个素材，通过服务器原生声音包播放，验证声音分类、位置衰减、非循环、实际活动声道与结束回收；同时保留批次特效的真实世界接收／绘制／过期／退出验证。正式玩家存档不参与测试。
- 原Godot工程按根目录统一入口隔离回归；模组声音实现未改Godot玩法代码。

首轮方块命中用例错误使用可穿墙的奥术，已改用土元素；失败运行不计为通过。正式听感、多人同时施法的混音平衡及长时服务器性能仍需后续体验验收。
