# 魔法附魔验收

2026-11-03 · 0.46.0 · 分支`codex/magic-enchantments`

新增6种功能附魔及9种元素庇护，数据包定义等级、权重、适用物品、属性效果和互斥；领域层新增受限磨损倍率与定量修复操作。服务端适配施法速度、伤害事件和每秒魔力维修，戒指通过Curios的槽位属性接口接入原版附魔修饰符。自带手册与Patchouli均添加双语说明。

## 结果

- `coreTest,runGameTestServer,build`通过：核心161569项检查、原生253项GameTest；新增6项附魔集成测试。
- 测试涵盖原版附魔台候选和真实铁砧输出，附魔互斥，属性修饰符与戒指槽身份，物品原生保存，实际释放冷却，护板不改变熔毁阈值，混合元素加权防护，原版受击间隔，以及小数基板维修、实际扣魔、背包排除、耗尽板修复、熔毁板拒绝与饰品维修。
- `runClient -EnchantmentSmoke`通过。在独立临时世界实际装备附魔法袍与戒指，客户端观察到法强1.8、容量加成512，总容量576；HUD显示576上限。保留截图于`docs/images/enchantments/`，成功标记`ENCHANTMENT_GPU_PASS`。
- 401个Java文件通过AOSP四空格排版检查，相关改动通过`git diff --check`。
- 安装包检查确认原生模组版本为0.46.0、包含15份附魔定义，不含测试类；发布副本SHA-256与构建产物一致，清单及推荐版本已更新。

验证均使用`build`下隔离世界。GameTest中的损坏存档错误日志来自既有负向测试，客户端离线验证出现的Mojang身份服务访问失败未影响世界进入、属性同步或截图。没有执行正式世界升级测试、长期多人测试或第三方附魔模组兼容性测试。

## 边界

迅咒沿用既有0.25至2倍有效速度范围，只影响实际施法装备。魔力维修为宝藏附魔，使用标准玩家魔力扣费及恢复等待；按实际修复量计价，未熔毁基板修复不自动起阵，熔毁仍须工作台更换。元素庇护只减对应魔法伤害，不重新结算已完成反应，也不把环境伤害归类成魔法。
