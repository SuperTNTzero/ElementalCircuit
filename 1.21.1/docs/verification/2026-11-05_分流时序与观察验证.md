# 分流、时序与观察验证

版本：0.52.0。分支：`codex/control-observation-runes`。未暂存、提交或推送。

## 实现范围

新增元素筛分、信号择路、信号延时、世界锚定、目标筛选、探知六种符文。补齐具名源出口、联系解除入口，以及存储的已满、可释放、已空状态出口。新蓝图在魔力搬运前统一采样控制，保留旧协议采样语义；没有新增通用数值或向量线路。

筛分和择路保持来源账本、到达顺序及资源守恒，缺少出口时阻塞。延时使用共享节点的不可变FIFO，固定步推进并完整保存变化队列。锚点进入独立世界联系现场；目标筛选不绕过地形，探知不调用世界或库存操作。重复世界查询按宿主、观察模式、世界步合并；容器槽数读取一次并冻结，负数及超预算能力拒绝检查。

静态图集由本机Inkscape 1.4.4导出，共87个符形。原生手札和Patchouli共用31条双语条目。网络协议为 `1.21.1-24`，蓝图4、新现场13、世界联系SavedData 2；历史数据显式兼容。另修正了安装包元数据停留在0.50.0的问题，使运行时版本与0.52.0文件名一致。

## 验证结果

| 项目 | 结果 |
|---|---|
| `build` / `coreTest` | 168,406项断言通过 |
| `runGameTestServer` | 282项原生测试通过 |
| 新符文客户端交互 | 具名魔力出口真实布线、存储状态出口选择、延时回车保存通过 |
| 既有编辑器GPU回归 | 参数折叠、编辑文字保留、侧栏位置、连线模式Delete、撤销通过 |
| 小窗口 | 320×240逻辑像素下参数滚动及回车保存通过 |
| 安装包核验 | 元数据0.52.0、实际新增运行类存在，SHA-256已计算 |

核心新增检查涵盖：筛分成分及来源、阻塞守恒、多出口蓝图及重布线、信号择路；2,500步随机高低和有效性变化延时、在途队列读档、继续运行逐步一致、停阵冻结、复位与损坏时间拒绝；持续高电平防止联系重锁、存储独立状态及恢复。

原生新增检查覆盖：转向与读档后的世界锚点不变；损坏锚点保留原数据；筛选跳过非目标实体但不穿墙；解除仅作用于指定联系；真实容器的空、满、差一物品状态；探知不改动库存；动态槽数只读一次且检查有界。

使用命令：

```powershell
./tools/build.ps1 -Offline -Mirror -Tasks build,runGameTestServer
./tools/build.ps1 -Offline -Mirror -ControlSmoke -Tasks runClient
./tools/build.ps1 -Offline -Mirror -StandardSmoke -Tasks runClient
```

原始日志位于 `build/control-final-verification.log`、`build/control-ui.log`、`build/control-compact-ui.log`。测试使用新的隔离GameTest目录和不创建世界的独立客户端目录，未读取正式世界。运行中的平台WMI、离线公钥请求、开发环境Patchouli告警不作为玩法验证结论；所有测试以完成标志和退出码判定。
