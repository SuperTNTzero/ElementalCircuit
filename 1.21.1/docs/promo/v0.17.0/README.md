# 0.17.0宣传参考素材

本目录包含五张Minecraft客户端渲染的界面图，以及用其中一张制作的封面草案。截图使用独立展示数据，未连接游戏世界；不能标成连续生存操作录像。游戏效果沿用0.16.0，完整游戏镜头按 [分镜](../../首支宣传片脚本.md) 另录。

| 文件 | 内容 |
|---|---|
| [inscription.png](inscription.png) | 五符文火球法阵、折叠目录与刻印页 |
| [wand-workbench.png](wand-workbench.png) | 紫晶杖端预览、组装属性与部件列表 |
| [blueprint-notebook.png](blueprint-notebook.png) | 三页蓝图及选页预览 |
| [spellbook.png](spellbook.png) | 多法阵法术书 |
| [element-switching.png](element-switching.png) | 火水交替法阵与计数器设置 |
| [cover-draft.png](cover-draft.png) | 1280×720封面草案 |
| [captions.zh-CN.srt](captions.zh-CN.srt) | 42秒分镜字幕，可在剪辑时调整时间 |
| [sources.json](sources.json) | 截图尺寸、来源和SHA-256 |

界面原图为1280×800，封面没有改变游戏内法阵内容。生成步骤见 `tools/prepare-promo.py`，运行前先完成 `-Showcase` 客户端截图。
