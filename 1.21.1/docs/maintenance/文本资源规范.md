# 文本资源规范

所有可见文本、操作提示、聊天反馈、验证错误和手札内容均属于资源数据。界面文本使用 Minecraft 本地化键，例如 `Component.translatable("screen.elementalcircuits.blueprint")`；需要作为字符串传给自绘控件时使用 `UiText.string(key, arguments)`。领域层和服务端非组件接口使用 `Texts.get(key)`，只保存键与参数语义，不在 Java 中写自然语言。

新文本同时添加到 `assets/elementalcircuits/lang/zh_cn.json` 与 `en_us.json`。键按用途命名：`screen.*`、`ui.*`、`tooltip.*`、`message.*`、`rune.*`、`configuration.*`。含动态值的文本用 `%s` 参数，不在 Java 中拼接完整句子。蓝图手札/Patchouli 正文继续按其现有语言目录放在 JSON 条目中。

提交前运行 `python tools/maintenance/check-texts.py`。该检查确认语言键集合一致、英文资源不含中文、静态代码引用存在、所有符文均有名称和说明，并拒绝生产 Java 源码中的中文文字字面量。新增界面文案不得通过 `Component.literal` 放入 Java。
