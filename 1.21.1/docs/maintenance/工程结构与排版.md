# 工程结构与排版

本次整理针对 Minecraft 1.21.1 工程。法阵、魔力与世界存档格式保持原有版本，注册 ID 和资源 ID 保留；Java 包名按职责调整。引用 Java 类型的外部开发代码需要更新 import。

## 源码入口

`src/main/java/dev/elementalcircuits/` 按运行边界分层，子目录使用包名表达具体职责。

| 目录 | 职责与入口示例 |
| --- | --- |
| `domain/circuit` | 法阵定义、VM、槽位、叠阵与互联；`TickCircuit`、`CircuitAssembly` |
| `domain/mana` | 数量、供给、存储、场与返还；`Mixture`、`ManaPool` |
| `domain/casting` | 参数、成本、时序、几何和递归触发 |
| `domain/combat` | 元素队列、反应和伤害计划 |
| `domain/equipment`、`logic`、`book`、`survey` | 部件、时序逻辑、蓝图与探测纯规则 |
| `domain/examples` | 领域层示例构造器；编辑器不提供测试模板按钮 |
| `application/runtime`、`observation` | 调度与只读观察模型 |
| `server/circuit`、`casting`、`spell` | 原生宿主、法杖释放与世界法术结算 |
| `server/mana`、`equipment`、`workshop`、`probe` | 玩家与世界魔力、装备、工作台、探测适配 |
| `client/screen`、`input`、`hud`、`registration` | 页面、按键、HUD 与客户端注册 |
| `client/editor` | 不依赖原生窗口的编辑模型、布局与命中计算 |
| `client/render`、`effect`、`book`、`guide` | 静态资源、特效、书本动画与指南阅读 |
| `adapter/config`、`codec`、`resources`、`persistence`、`compat` | 配置、编解码、静态规则、NBT 与可选模组接口 |
| `block`、`item`、`network` | 注册对象及网络意图入口 |

少量坐标、定点等跨子系统基础类型保留在 `domain/` 根目录。领域和应用层保持不依赖 Minecraft、NeoForge、客户端与服务端适配类，既有架构测试继续检查这条边界。

## 资源、工具与文档

运行资源在 `src/main/resources/`，Blender 与 Aseprite 原稿在 `art/`，依赖在 `libs/`。构建、截图和隔离测试世界在 `build/`。文档按 `systems`、`art`、`verification`、`maintenance` 分类，统一入口为 [文档导航](../README.md)。

`tools/artwork/` 集中模型、贴图、音效与导出脚本。脚本使用自身文件位置解析工程根目录。原有构建和测试命令继续放在 `tools/`：

```powershell
./tools/build.ps1 -Tasks build,runGameTestServer -Mirror -Offline
./tools/test-core.ps1
./tools/test-blueprints.ps1 -Mirror -Offline
./tools/format-java.ps1
./tools/format-java.ps1 -Check
```

格式化器使用 Google Java Format 1.24.0 的 AOSP 四空格风格。脚本读取相邻 `tooling/formatters/` 的固定版本 jar；也可通过 `-FormatterJar` 指定，运行时不会下载。格式化工具版本、来源和哈希见该目录的 README。

Java 文件采用四空格缩进，运算符、实参和控制语句保留空格，字段、构造器和方法之间留空行；长调用展开，import 与 package 随实际目录维护。`.editorconfig` 为新增文件提供 UTF-8、换行与缩进默认值。不要对依赖 jar、Blender 二进制或自动生成的模型进行文本格式化。

## 手册手持模型

`models/item/circuit_guide.json` 使用 NeoForge 的 `separate_transforms`。第一、第三人称的左右手选择 `guide/held`；其余显示上下文选择原有平面物品模型，因此物品栏、掉落物和展示框使用书本图标。

原稿在 `art/blender/guide/field-guide.blend`，模型为 208 个顶点、156 个四边形。深蓝封皮、黄铜包角、纸页和蓝色书签共用一张 256×128 像素图集；运行时使用烘焙静态模型，不增加逐帧生成网格。书页内容仅作外观，实际指南仍由现有阅读器打开。

重建步骤见 [美术工具入口](../../tools/artwork/README.md)。模型截图与本次验证记录见 [手册模型与目录整理验收](../verification/手册模型与目录整理验收.md)。
