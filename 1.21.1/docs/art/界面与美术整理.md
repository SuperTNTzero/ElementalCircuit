# 界面与美术整理

2026-10-30 · 0.17.0 · Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21

本次只整理界面、美术和玩家文本，沿用0.16.0的施法效果。分支为 `codex/ui-art-polish`，没有暂存、提交或推送。1.20.1工程与之前的安装包保留。

## 画面

刻印页、法杖工作台、法术书、蓝图簿和分享页使用同一套深色底板、黄铜边饰和浅绿提示色。主要操作用金色突出，选中项保留侧边标记和键盘焦点；图标不再逐个套上六边形边框。格盘下增加静态刻度圆环，符文和连线保持原来的位置、命中范围与元素颜色。

法杖、部件、书册和基板重画为32像素贴图。27种组合法杖保留不同杖端、杖身和杖尾的轮廓；两种工作台有独立木纹、金属件和工作面，固定法阵保留明确的正面方向。没有改变合成、属性或世界作用。

## 操作与文本

- 选中符文后直接显示其参数，示例只在未选中符文时显示。换选其他符文会回到参数顶部，紧凑窗口也不必先翻过整组示例。
- 法杖工作台改为左侧大图预览、右侧部件列表，预览保持贴图比例；上方直接展示强度、速度、耐久和近战伤害。
- 刻印页底部只显示当前载体、法阵、供给状态、阵内魔力及“未保存”。部件属性留在工作台与物品提示中。
- “服务器验证”“运行现场”“预留预算”等实现用语从常用说明中撤下，改为“正在处理”“记得保存”“消耗部分魔力”等操作与结果。规则中的代价、次数和限制仍保留在符文提示里。
- 蓝图统一叫“蓝图码”；收录、载入和分享使用同一套措辞。独立蓝图簿不再显示两个作用相同的导入按钮。

## 资源与边界

`WorkshopSkin`只绘制静态九宫格贴图和底纹，不持有页面、网络、草稿或运行状态。`WorkshopLayout`是纯Java布局值，供预览与控件共同使用。输入仍由各Screen负责，权限、库存和保存仍由服务器负责。

资源制作入口为 `python tools/artwork/bake-art.py`，会调用 `bake-workshop.py` 和既有特效烘焙器。生成结果直接随JAR分发，游戏启动时不生成图片。旧 `generate-resources.py` 同时包含历史数据生成逻辑，不作为1.21.1资源重制入口。特效、音效、蓝图和世界保存格式未变；网络协议仍为 `1.21.1-2`。
