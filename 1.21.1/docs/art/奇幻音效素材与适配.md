## 改造后的声音

九种魔力各有释放、命中、屏障展开三阶段，另有公共起阵声。保留 28 个事件 ID；释放和命中各三个变体，屏障与起阵各两个，共 **74 个单声道 OGG/Vorbis**。原生声音系统按声音种子选择等权变体，声音随机不消耗玩法随机源。

| 元素 | 主体与细节 |
|---|---|
| 纯净 | 中性的短施法声、宝石触点 |
| 土 | 碎石翻动、低频石块落击 |
| 水 | 泼洒、水花、气泡与少量冰晶细节 |
| 火 | 火焰喷出、燃烧爆裂、火焰命中 |
| 风 | 气流掠过与短促风切 |
| 雷 | 雷鸣片段、锐利晶体瞬态 |
| 光 | 治疗魔法纹理、较高音域的宝石声 |
| 暗 | 降调、低通后的魔法与风声 |
| 奥术 | 魔法脉冲、晶体纹理 |

离线处理包括立体声折叠及相位抵消保护、45 Hz 高通、前后静音裁切、按元素调音与滤波、分层、短反射、柔性动态控制和淡入淡出。保留干声瞬态，命中声不等待混响。原始长尾被裁短并淡出；没有在客户端实时生成声音。

- 成品统一 **44,100 Hz、单声道、0.64–1.10 秒**；按原生声音事件进行空间衰减、字幕和“玩家”音量控制。
- 合计 **788,591 字节** OGG；全部解码后的 16 位单声道 PCM 载荷约 **5.04 MiB**，未把原始包或 WAV 塞入 JAR。
- 对编码后重新解码的波形做 4 倍过采样峰值检查；本次范围 0.378158–0.819126，RMS −24.20 至 −16.46 dBFS，5% 峰值门槛的起音位置 0.45–18.59 ms。此项衡量的是素材自身，不包含设备播放延迟。
- 世界每步 64 条、每玩家最近 8 条、24 格距离、4 格单元合并和分阶段冷却保持原有策略。短音预载，屏障只在建立时播放一次，不增加常驻循环声道。

- [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)：作者署名与许可例外；JAR 同时包含本文件及两份官方许可原文。

重做音频：

```powershell
python -m pip install --target build/audio-tooling -r tools/artwork/requirements-audio.txt
python tools/artwork/bake-audio.py --tooling build/audio-tooling
```

脚本只读本地源文件，先校验哈希再处理；无需联网抓取素材。输入及混音参数被记录，编码字节仍取决于 libsndfile/Vorbis 的版本。离线工具、源码包、试听 WAV 不进入运行时。
