# 联系施法与空间参数

适用版本：Minecraft 1.21.1，模组 0.55.0。

## 符文组合

| 符文 | 职责 |
| --- | --- |
| 联系 | 新施法方式。射线锁定一个实体或方块；每个载体、槽位、输出符文拥有独立联系。 |
| 施力 | 对实体沿出射方向持续施力，反相魔力反向。连续数值表示强度，默认 1。 |
| 约束 | 对实体施加有限弹力和阻尼，追随出射方向上的参考点；默认强度 1。 |
| 交互 | 读取实际信号线电平，每个上升沿操作一次原版拉杆、按钮或钟。没有信号线时不操作。 |
| 角度 | 扇形完整张角，1—180°，默认 70°；支持小数。首期仅接受扇形。 |
| 偏转 / 俯仰 | 水平 ±180° / 垂直 ±90°；正值分别向右、向上。 |
| 联系距离 | 约束参考距离，0.5—256 格；缺省保持初次锁定距离，受射程和服务器上限限制。 |

联系不自动搬物、伤害、采集或读写容器。施力和约束仅影响生物与掉落物，不移动地形。联系不搭配形状、投射物派生或容器端口；不兼容组合保留原有输出冲突处理。容器读取、容器输出和土元素自动化继续使用原有路径。

典型通路：`输入 → 风转化 → 联系 → 约束 → 输出`。可在输出前增加联系距离；开启持续运行，多次输出为同一联系补充额度。另一例：`输入 → 联系 → 交互 → 输出`，另将红石感应、节拍器等信号接至交互。若交互与开关同时受红石驱动，低电平仍须有一股魔力经过交互，输出端才能观察到下降；否则不会制造新的上升沿。

手持法杖时，含联系符文且已设为持续的法阵，在点击或蓄力释放后按持续配置供能，再次右键停止。也可将红石/内部信号接入该联系符文作为释放信号：信号上升时解除对应联系并在高电平期间禁止重建，信号回低后才允许下次锁定。目标死亡/卸载、遮挡、超距或预付维护额度耗尽也会自动解除；固定法阵在断供或停阵时立即撤销宿主权限。其他法阵继续按原有单次手势施法。固定法阵仍由调律杖启动、停供。单次联系仅在本次供给开启期间有效；要持续搬动实体，请使用持续配置。

`src/test/resources/blueprints/contact-constraint.ecblueprint` 提供可导入的“联系悬停”示例。现有 `tools/test-blueprints.ps1 -Offline -Mirror` 会在隔离测试世界中把索引内的16张蓝图注入蓝图簿，不增加编辑器测试按钮。

## 生命周期与结算

源由宿主在每个世界步重新确认：仍拥有物品、仍佩戴装备、固定载体有效、法阵供给开启且基板未熔断。联系余额不能代替该权限；停阵、宿主失效或断供立即解除。余额不足维护费、目标死亡/卸载/超距、视线被实体墙阻断也解除。关闭服务器选项会解除已有联系。区块不会由联系强制加载。

首次建立联系消耗一次法杖施法间隔；同一已建立联系的后续供能只补充原目标的预付效果额度，不再次触发法杖冷却，也不重新选中准星下的其他目标。参数变化则重新建立。源位置与视线每个世界步更新。联系失效后，持续法阵可以按冷却重新锁定；若需保持终止状态，应保持释放信号为高。余额不可回流、不可返还；维护停机不修改原实体的重力、拾取归属等状态。

每tick先支付维护费：

`M = maintenance + distanceCost × d² + loadCost × L`

其中 `d` 为源到目标中心的距离，实体负载 `L = max(0.25, 宽² × 高)`，方块按 1。初值分别为 `0.02 / 0.0001 / 0.005`。每项最终成本向上量化到 1/65536 魔力。

施力请求的速度增量为 `0.05 × min(32, 强度 × 法强 × 杖强) × 正反相比例 × 出射单位向量`。约束额外使用弹力 `min(1, 0.12 × 强度 × 法强 × 杖强) × 位置误差`、`0.35 × 速度` 阻尼，并在预算内补偿原版重力。约束参考点遇墙时向源侧缩回，目标本身遇遮挡则解除。

单实体每tick所有联系合计冲量初限为 `0.15`，大型目标再受负载限制；总速度初限 `0.8`。实际施加的冲量另付 `workCost × L × 冲量长度`，系数默认 `0.25`。不足费用时不施力；不传送、不取消原版碰撞。交互每次默认花费 `1`，取消事件不返还本次操作的已付费用。多个信号上升沿在同一世界步内合并为至多一次操作。

使用已经支付输出成本的效果额度供能；法强与减耗仍经过统一输出报价。混合魔力先按实际到达队列抵消，剩余反相奥术不能资助物理操作。联系本身不附加元素伤害或火、水等地形效果。

## 空间参数与特效

角度改变扇形体积归属和方块足迹；成本缓存包含张角，不能与另一张角串用。服务端批量特效消息携带实际张角，客户端的外沿、填充和元素喷流使用相同角度。网络协议升为 `1.21.1-23`，双方需升级。

偏转、俯仰先于散布应用；未放置这些符文时保持原有方向。联系不使用随机散布，避免锁定目标随输出序号抖动。首次锁定会显示施法启动环和目标命中脉冲，并播放对应元素的施法/命中音；联系维持期间每两tick更新较宽的元素束，续供不重复播放启动爆发。上述观察丢失或渲染失败不影响目标、冷却、费用或物理。

## 配置与保存

服务器 `contact.*`：`enabled`、`maxLinks`（每维度默认 128）、`perOwner`（默认 16）、`range`（默认 64）、`maintenance`、`distanceCost`、`loadCost`、`workCost`、`interactionCost`、`maxImpulse`、`maxSpeed`。和既有配置一样可通过管理命令查询/修改。

独立世界 SavedData `elementalcircuits_connections` v1 保存出口身份、所有者、目标 UUID / 方块类型、初始参考距离、预付余额、法杖强度、信号电平、待执行交互及法术参数。源姿态和当前权限由宿主在恢复后的第一步重建，不能从存档凭空生成。非法现场保留原 NBT 并停用。旧法术缺少新维度时显式补为空，不改变旧法阵形状。

扩展新的联系效果应增加独立效果维度与执行适配；扩展可交互方块应增加明确的原版动作适配，不能开放任意 GUI 或库存访问。首期不支持容器远程开屏、移动车辆、骑乘目标或搬运方块。
