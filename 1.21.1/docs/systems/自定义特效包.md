# 自定义特效包

自定义特效以客户端本地 `.ecfx` 文件导入，不使用 Minecraft 资源包，也不依赖资源包重载。`.ecfx` 是 ZIP 容器，扩展名需保持为 `.ecfx`，文件名（不含扩展名）必须与清单中的 `id` 相同。把包放入游戏目录下的 `config/elementalcircuits/effects/`，进入世界时加载；同 ID 重复包只使用排序靠前者。最多载入 32 个包，单包不超过 16 MiB，包内单文件不超过 8 MiB。

包根目录仅接受以下文件：

```text
ember.ecfx
├── manifest.json      必需
├── spritesheet.png    必需
├── cast.wav           可选；清单引用时必需
└── hit.wav            可选；清单引用时必需
```

PNG 是自定义逐帧贴图，不要求来自模组现有资源。贴图按从左到右、再从上到下编号；每格尺寸由清单指定。总图最大 1024×1024，帧格边长 8–512，最多 64 格。制作新动画时，将任意逐帧绘制结果排成等尺寸网格即可。

清单格式如下，`frames` 中的数字是贴图格编号：

```json
{
  "version": 1,
  "id": "ember",
  "frameWidth": 64,
  "frameHeight": 64,
  "cast": {
    "frames": [0, 1, 2, 3],
    "fps": 20,
    "loop": false,
    "opacity": 0.95,
    "scale": 0.8,
    "pulse": 0.15,
    "sound": "cast.wav"
  },
  "hit": {
    "frames": [4, 5, 6, 7, 8],
    "fps": 30,
    "loop": false,
    "opacity": 1.0,
    "scale": 1.2,
    "pulse": 0.25,
    "sound": "hit.wav"
  }
}
```

`cast` 是施法过程，`hit` 是命中特效；两者都必须提供。`fps` 范围 1–60，`opacity` 和 `pulse` 范围 0–1，`scale` 范围 0.1–4。`loop` 为真时循环播放帧序列。省略 `sound` 即不播放该阶段声音；指定时只能使用包根目录的对应 WAV 文件。音频限 8 秒、8–96 kHz、单/双声道、8/16 位 PCM WAV。

将清单、PNG 和可选 WAV 打包到 ZIP 根目录后，把 ZIP 改名为 `ember.ecfx`。`config_examples/effects/ember/manifest.json` 提供清单样例。无效或超限的包会整体跳过，不影响其他包。导入动画只控制客户端视觉和本地音效，不改变法术命中、伤害或世界状态。
