# 基板承载、独立耐久与熔毁

版本：0.43.0，2026-11-02。适用 Minecraft 1.21.1 / NeoForge。

基板承载按实际魔力总量检查，不缩小输入参数。输入设512，玩家有512时完整注入；玩家只有56时整次供给失败，不扣56，也不按虚构的512触发爆炸。

## 基板和杖体

| 基板 | 安全承载 C | 熔毁阈值 F=4C | 新基板耐久 |
| --- | ---: | ---: | ---: |
| 木质 | 128 | 512 | 256 |
| 黄铜 | 512 | 2048 | 1024 |
| 水晶 | 1280 | 5120 | 4096 |

这些都是服务器初值。每个槽位拥有独立基板，同槽位的主阵与叠阵共享基板状态。法术书、装备和固定法阵都通过同一宿主保护接口检查。副手书阵消耗书中基板，杖内未使用的基板不受影响。

近战只扣杖体1耐久。成功施法的杖体损耗为此前分段磨损公式的5%，累计小数后才扣整点；基板损耗独立计算。基板损坏不销毁法杖、不扣剩余杖体耐久，也不阻止近战。杖体耗尽仍沿用原来的损坏规则。创造模式不产生两类磨损或熔毁，仍支付实际输入魔力。

## 检查时刻和负载

每逻辑刻完成到达包、自然衰减和实际供能后，在符文运算、转发或输出前检查。M为本基板拥有的魔力：回收储量、符文暂存、专用存储、输入队列、在途线路和待发送端口之和。已输出魔力和已归属来源的退款凭据不计入M。

输入、汲取与跨阵接收都经过检查。分多次注入不能规避限制：木板存储先注入300，再注入300，累积量达到512时熔毁。普通损耗与自然衰减使实际累积量稍低于简单相加。

每次只收取新增实际供给的基础磨损，保存的供给游标防止读档或重复观察再次计费。旧存档初始化健康基板，游标从原有累计供给开始，不追溯补扣历史磨损。

## 基板磨损

I为自上次检查后新增的实际供给量，x=max(0,M/C−1)。每刻（20Hz）新增耐久损耗：

`ΔW = a × I/4 + b × x²/20`

初值a=0.125，b=8。正常输入4魔力消耗0.125基板耐久；两倍承载额外损耗8耐久/秒，三倍承载额外损耗32耐久/秒。小数以16.16单位保存。控制信号的微量实际供给也计费。

M＜4C时只磨损。耐久耗尽立即清空板内魔力并断供，拒绝起阵与接收，不爆炸。M≥4C时直接熔毁、耐久归零，触发一次爆炸；先保存损坏记录，再调用原生爆炸事件，避免回调或死亡导致重复触发。

## 熔毁公式

元素烈度H为板内元素占比的加权平均。默认：纯净/水0.6、火1.5、雷1.4、风/光0.8、暗1.1、奥术1.25、土1.0；反相沿用对应元素权重。

刚进入法阵、尚未元素化的纯净魔力，使用从供能符文沿魔力线路可达的元素转化刻印计算烈度，按刻印数均分。已经元素化的魔力按实际成分计算。这个规则只预测爆炸烈度，不额外转化魔力、不模拟开关状态，也不提前造成元素反应；没有可达转化时按纯净计算。

F=kC，初值k=4：

`E = H × (M/F) × [1 + max(0,(M−F)/C)]`

`R = min(Rmax, r × ∛E)`

`D中心 = min(Dmax, d × √E)`

`D实体 = D中心 × max(0,1−距离/R)² × 原版遮挡暴露率`

初值r=2、d=6、Rmax=8格、Dmax=80点伤害。木板火元素在512魔力时：E=1.5，R约2.29格，中心伤害约7.35点。1024魔力时：E=15，R约4.93格，中心伤害约23.24点。

使用现有`ec_damage/mixed`伤害类型，经过原生爆炸事件、声音、粒子、击退、护甲与受击间隔，不逐元素重复扣血。施法者也会受伤，其他玩家受现有PvP权限限制。方块破坏可关闭，开启时检查已加载区块、世界边界和玩家修改权限，并限制在公式半径内。

## 修复和持久化

法杖改用暗化裂纹静态贴图；HUD和管理页显示损坏/熔毁。槽位列出耐久与承载量。模型保留完整杖体及部件形状，损坏的是内部基板。

停供后持原物品右键法阵工作台，进入“基板管理 → 基板”，点击“修复当前基板”。消耗一张同材质基板，恢复该槽位耐久，保留主阵、叠阵、连接与杖体耐久。固定法阵先用探测杖选定，再在附近工作台处理。更换材料照常消耗新板；受损旧板不回收成完好的空白板，避免来回换材免费修复。

修复不退还耗散魔力，也不自动起阵。蓝图不保存耐久，套用蓝图不会修复。旧程序集显式迁移到v4，保留VM现场、法阵身份、时钟、元素顺序和账本。网络协议升级为`1.21.1-21`，客户端与服务器需同时更新。

已发射的递归投射物沿用发射时冻结、已支付的预算，不再次读取玩家背包扣基板耐久；根阵在发射前已检查完整输入。途中修复或换书不会回溯改变它。

## 设置

世界`serverconfig/elementalcircuits-server.toml`的`board`组，或已有管理指令`/ec config set <键> <值>`：

| 键 | 含义 |
| --- | --- |
| `board.woodCapacity/brassCapacity/crystalCapacity` | 三种材质安全承载 |
| `board.woodDurability/brassDurability/crystalDurability` | 新装和修复的最大耐久，不改写已保存最大值 |
| `board.fuseMultiplier` | 熔毁阈值倍率，初值4 |
| `board.inputWear/overloadWear` | 上式a、b |
| `board.wandWearScale` | 杖体施法磨损比例，初值0.05 |
| `board.blastRadius/blastDamage` | 上式r、d |
| `board.maximumBlastRadius/maximumBlastDamage` | 爆炸预算上限 |
| `board.breakBlocks` | 1破坏方块，0只作用实体 |
| `board.volatilityPURE/FIRE/WATER/EARTH/WIND/LIGHTNING/LIGHT/SHADOW/ARCANE` | 各元素烈度，逐项配置 |

承载、磨损和爆炸系数按当前服务器设置生效，停供时修改更便于观察。输入量与符文范围仍由原有配置管理；提高承载量不补充魔力。
