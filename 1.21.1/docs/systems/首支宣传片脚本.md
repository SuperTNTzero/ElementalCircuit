# 首支宣传片脚本

定位：约42秒的玩法开发预览。让观众看到一张法阵怎样变成法术，以及玩家可以怎样改它。片名用“元素法阵｜玩法开发预览”，封面文案为“画法阵，造法术”。

| 时间 | 镜头 | 屏幕文字 |
|---|---|---|
| 00–03秒 | 实际火球命中，保留起阵、发射和命中声，迅速切入主题 | 元素法阵 |
| 03–08秒 | 刻印页放下输入、元素、方式、形状、输出，接上魔力线；剪掉等待和反复找按钮的过程 | 画一张法阵 |
| 08–14秒 | 加上追踪与命中分裂，保存后对一组目标施放，镜头停到子弹分开 | 给火球加上追踪和分裂 |
| 14–19秒 | 切换火与水；各给一次世界接触近景，展示火焰与水源 | 换成水，再试一次 |
| 19–24秒 | 工作台切换石英与紫晶杖端，展示轮廓和属性变化，安装后拿在手上 | 组装自己的法杖 |
| 24–29秒 | 副手法术书切换当前法阵，紧接一次对应施法；保留切换HUD | 把法阵收进法术书 |
| 29–34秒 | 两个真实连接的固定法阵，一端供给、一端输出；构图中同时看见两台设备 | 固定法阵也能相互连接 |
| 34–38秒 | 蓝图簿选页、复制蓝图码，另一页载入后显示相同法阵 | 蓝图码，复制即分享 |
| 38–42秒 | 回到最醒目的一次法术释放，再停在片名与平台信息 | Minecraft 1.21.1 · NeoForge / 开发预览 |

录制用单独世界，准备木制工坊、清晰的石墙靶场和一段可以展示火水接触的地面。先录一遍“画阵→保存→起阵”的真实操作，再分别补录近景。战斗镜头关闭F3与聊天，不隐藏关键的切阵反馈；界面镜头使用适合录制分辨率的GUI缩放，让文字在成片里仍能读清。建议录制1920×1080、60帧，帧率以实际录制稳定性为准。

剪辑先按声音切点衔接：起阵、发射、命中各留一个清楚的瞬间，字幕每镜头一句。前十秒出现真实施法和编辑，不先铺一段功能清单。背景音乐后加，并给游戏音效留出空间。

当前已导出的是五张实机渲染的**界面参考图**、一张封面草案及可导入剪辑软件的SRT字幕，尚未录制上表的完整连续游戏素材。参考图使用独立展示数据，批量特效测试图也不充当战斗录像。参考素材生成命令：

```powershell
./tools/build.ps1 -Tasks runClient -Showcase -Mirror -Offline
python tools/prepare-promo.py
```

这版适合先发布开发预览，讲清楚可操作的玩法；正式发布日、多人长期稳定性和完整生存平衡暂不写进片尾承诺。
