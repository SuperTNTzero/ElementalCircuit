# 法袍、戒指与装备施法

版本：0.36.0。目标：Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21。

## 安装

同时安装本模组和 **Curios API 9.5.1+1.21.1**，客户端与服务器都需要。原 Baubles 最后支持 1.12.2，不能装进本版本；这里使用 Curios 提供的真实饰品槽，没有另造一套背包。默认增加两个戒指槽，可与其他 Curios 装备共存。

Curios 官方项目：https://github.com/TheIllusiveC4/Curios/tree/1.21.1 。开发依赖锁定在 `libs/manifest.json`，使用官方未修改 API 与运行 jar；不把 Curios 打入本模组。依赖、源码及许可在 `releases/dependencies/` 与 `licenses/curios/`。

## 制作与属性

帽、袍、绑腿、靴和铭文戒指都用皮革与魔力水晶合成。L 为皮革，C 为魔力水晶，空格留空：

| 成品 | 上行 | 中行 | 下行 |
|---|---|---|---|
| 晶缀巫师帽 | ` L ` | `LCL` | `LLL` |
| 深蓝法袍 | `L L` | `LCL` | `LLL` |
| 缀晶绑腿 | `LLL` | `LCL` | `L L` |
| 缀晶长靴 | `L L` | `LCL` | 空行 |
| 铭文戒指 | ` C ` | `L L` | ` L ` |

获得魔力水晶后解锁配方书中的对应配方。法袍可用皮革或魔力水晶修补。

| 部件 | 法强增加 | 魔力容量增加 | 固定回复增加/秒 | 护甲 |
|---|---:|---:|---:|---:|
| 巫师帽 | 0.10 | 16 | 0.50 | 2 |
| 法袍 | 0.20 | 32 | 1.00 | 5 |
| 绑腿 | 0.15 | 24 | 0.75 | 4 |
| 靴子 | 0.10 | 16 | 0.50 | 1 |
| 合计 | **0.55** | **88** | **2.75** | **12** |

基础法强为 1，穿齐后为 1.55；伤害乘 1.55，魔力成本乘 `1.55^player.spellPowerCostExponent`，指数仍默认 1。戒指用于承载法阵，不额外增加上述属性。

装备属性使用原生同步 Attribute：`spell_power`、`mana_capacity`、`mana_regeneration`。容量与恢复属性都代表装备额外值，默认 0。可与原版属性指令和物品属性修饰组件组合使用。

有效容量 = 永久容量 + 装备容量；永久容量仍由魔力果实与管理员设置改变。果实的 1024 上限只约束永久成长。因此永久 1024 穿齐后可达 1112。穿戴、修补和重新登录都不补充当前魔力；卸下装备会截断超过新有效容量的部分。反复穿脱不会刷永久容量或魔力。

恢复沿用混合公式：

`每秒恢复 = (玩家固定恢复 + 装备固定恢复) × 药水倍率 + 有效容量 × 百分比恢复`

药水只影响固定分支，消费后的等待仍保留。玩家槽现场升级到 v2，分别保存永久容量、装备额外容量和当前量；v1 迁移为额外容量 0，不补能。管理员 `mana capacity` 调整的是永久容量。

## 刻印和操作

先把装备拿在主手，右键**法阵工作台**刻印；保存后穿戴。戒指放进 Curios 戒指槽。仅放在普通背包或主手时不能使用装备施法快捷键。

装备沿用现有的有限魔力法阵、四个槽位、材料、叠阵与蓝图规则。基板更换和新槽位继续消耗材料板。不会初始附赠已完成的法术。

默认按键：

- 按住 **V**：装备法阵轮盘。移动指针后松开选择；中心区域或 Esc 取消。每页最多八项，滚轮翻页。
- **J**：施放所选装备、所选槽位的法阵。
- **H**：施放所选戒指的当前槽位；当前选择不是戒指时，使用第一个已装备的戒指。
- 轮盘中右键某一项：切换该装备槽位的“手动 / 受击”触发。默认手动。

Curios 的默认 G 键保留为打开饰品栏，装备施法采用未占用的 J 键。按键可在原版控制设置中修改。界面、聊天和输入框打开时不提交施法按键。装备选择和戒指施法均由服务器再次验证穿戴状态与物理物品身份。

每件装备独立冷却，槽位共用该件装备的冷却；不借用主手法杖的部件、耐久或冷却。速度按 1 计算，间隔使用现有施法冷却规则。装备损坏仍由原版护甲规则处理。

一次装备施法从固定输入取能，首次输出后停止本次供给。已有在途魔力继续运转；本件装备有活动现场或尚未冷却时不能再次起阵。无输出或封闭回路也遵守现有有限运行窗口、缓存损耗和退款规则。卸下装备立即停止新增供给与输出；留在背包里的缓存继续衰减。

## 受击触发

受击是**起阵条件**，与“范围 / 指向”等输出方式分开。设为受击后不能同时用 J/H 手动触发；法阵自身仍决定输出形状、元素和叠阵关系。

只监听原版已经接受、实际伤害大于 0 的 `LivingDamageEvent.Post`。取消的伤害、原版无敌帧拒绝的命中、零伤害及致死后无有效玩家的情况不启动法阵。接受原版受击间隔，不清除 `invulnerableTime`。

每件装备一次受击最多启动一个受击槽位，优先本件装备当前选中的槽位，再按已有槽位顺序选择。不同部件可以分别响应，但都从同一个玩家魔力槽付费。指向默认朝伤害来源；没有实体来源时沿当前视线。

反击输出带有 `reactive` 来源标记，穿过法术修饰、投射物存档、二次分裂、连锁与递归子阵；它仍遵守元素反应、法强、成本和原版伤害规则，但**不再次触发装备反击**。因此普通魔法命中可以引发反击，反击链不会双方无限互相启动。这个规则与冷却共同生效，不依赖双方弹道距离。

## 界面和美术

编辑器的槽位、阵层和工具分别为居中行；槽位在最上方，阵层按钮较小。管理页父项缩进，子项进一步缩进且更窄、更矮。

法袍为独立 3D 人形骨骼模型：深蓝布料、黄铜饰边、切面水晶、弯顶巫师帽；胸部、袖子、左右分袍、绑腿和靴子分别随对应骨骼运动。穿袍时绑腿的装饰藏在外袍下面，避免表面重叠闪烁。

Blender 源文件：`art/blender/wizard/wizard-equipment.blend`。可重复生成脚本：`tools/artwork/model-wizard-blender.py`。运行时从 `assets/elementalcircuits/models/armor/wizard.json` 烘焙模型，原版负责姿态、附魔光和渲染；没有每帧重建网格。两张盔甲贴图为 128×128，物品图标为 32×32。
