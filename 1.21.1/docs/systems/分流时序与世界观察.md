# 分流、时序与世界观察

实现版本：0.53.0，Minecraft 1.21.1 / NeoForge 21.1.265。

## 六种基础符文

| 符文 | 配置与行为 | 组合用途 |
|---|---|---|
| 元素筛分 FILTER | 选定元素、正反极性；出口1送选中成分，出口2送其余成分。纯净不区分极性。 | 分离混合魔力、分别处理反相魔力 |
| 信号择路 SELECT | 信号低或无效走出口1，高走出口2。 | 两种输出间切换、条件分支 |
| 信号延时 DELAY | 默认10逻辑步，每步0.05秒；1–65536步。 | 延后动作、顺序控制 |
| 世界锚定 ANCHOR | 联系建立时固定参考点；联系距离决定最初距离，未设置则采用初次锁定距离。 | 与联系、约束组合悬停 |
| 目标筛选 TARGET | 0任意、1掉落物、2生物、3方块。 | 只抓掉落物，避免其他实体抢占 |
| 探知 PROBE | 0瞄准方块存在、1瞄准容器满、2本阵有联系、3本阵无联系。 | 条件供给、库存与联系反馈 |
| 边沿 EDGE | 0上升沿、1下降沿、2任一变化；每次变化输出一个逻辑步脉冲。 | 将持续信号转换为一次触发 |
| 限流 THROTTLE | 每个世界逻辑步允许通过的魔力量；出口1为额度内，出口2为余量，不设置内部缓存。 | 限制供能速度，单独处理溢出 |
| 物料筛选 MATERIAL_FILTER | 使用物品注册ID或`#命名空间:标签`筛选。 | 约束容器取料与拆解产物回收 |

锚定本身不施力，筛选不操作目标，探知不授予容器或修改权限。联系仍接受维护费用、负载、供能、遮挡与距离约束。非目标实体可被筛选跳过，方块始终阻挡射线。

## 明确出口与布线

选中符文后，右栏显示当前载荷的具名出口，点击即可开始布线。顶部也能选择出口编号。选中源符文时，其线路起始处标出出口编号。切换魔力/信号回到出口1；移动、撤销、文本码和保存均保留出口编号。

筛分先按成分划成两个互不重叠的集合，再在各出口内均分。对每种成分和供给来源：

`输入 = 出口1传输前份额 + 出口2传输前份额`

`实际交付 = 传输前份额 - 原有线路损耗`

保留到达先后与供给来源，反应和返还沿用原账本。缺少非空集合的出口时整批阻塞；有限在途魔力仍接受原有衰减，不复制、吞掉或变回纯净魔力。

## 存储状态与联系解除

存储增加三个独立信号出口：

1. 已满：`存量 ≥ 容量`。
2. 可释放：`存量 ≥ 释放阈值`且释放许可开启，不保证下游畅通。
3. 已空：`存量 = 0`。

新协议在全部魔力搬运前统一采样控制，信号沿线下一步生效。状态输出支付既有控制成本，不消耗被观察的存量；未接状态输出的旧存储不新增该费用。

联系的信号入口用于解除。高电平解除经过此联系符文的输出并阻止重建；低电平后允许重新建立。其他联系不受影响。VM出口和世界宿主双重检查在途包，避免同一步重锁。阻塞后的在途魔力遵守原有衰减、返还规则。

## 延时契约

`到期步 = 延时符文已运行步数 + 配置延时`

只在运行中的固定逻辑步推进，不读取渲染帧、现实时间或离线时长。初始输出无效，直到第一个延后样本到达。有效性变化也进入队列，不把失效偷换为有效低电平。保持先后与脉冲宽度；停阵冻结，重启继续，复位清空。

不可变双栈FIFO共享历史，正常入队出队摊销O(1)，序列化才展开数组。完整现场保存队列、运行步数、输入采样和当前输出；恢复校验时间、次序、大小及符文匹配。

## 世界观察与配置

瞄准探知默认读取16格内第一个已加载方块，不加载区块。容器满指每格均占用，达到物品和槽位堆叠上限中较小者；不是针对某种待插入物品的模拟报价。超过槽位检查预算时返回低。只读取能力与物品状态，不调用取出、插入、破坏、交互。

联系状态观察上一世界边界留下的联系，不预知本步新输出。同一宿主同一步的相同查询合并读取，停阵不发起探知扫描。

感应符文使用启动阈值和复位阈值形成迟滞：信号低于复位阈值时关闭，高于启动阈值时打开，处在两阈值之间时保留上一步状态。当前蓝图v5保存两个明确阈值。

| 配置 | 默认 | 范围 |
|---|---:|---:|
| `circuit.maxDelayTicks` | 65536 | 1–65536，仅限制新编辑，不删除既有现场 |
| `probe.range` | 16 | 1–64格 |

容器检查沿用 `automation.maxContainerSlots`，其他总量沿用既有服务器预算。高密度变化的长延时仍需要与队列长度成正比的内存和存档空间，未作大规模模组服压力验收。

## 当前协议

当前蓝图固定为v5，法阵现场固定为v14，法阵组固定为v4，魔力包固定为v3。解码器只接受当前格式；开发期旧蓝图、旧现场和缺少新字段的记录需要从当前编辑器重新保存或重建，不执行静默迁移。

世界联系SavedData与网络协议按各自领域版本校验，客户端和服务器需一同更新。

90个静态符形由 `art/inkscape/runes.svg` 通过Inkscape离线导出。原生手札和Patchouli共用双语条目。首批未增加通用数值/向量数据线、跨维度联系或区块强制加载；探知模式在服务器适配层留有扩展边界。
