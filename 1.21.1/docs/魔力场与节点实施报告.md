# 魔力场与节点实施报告

日期：2026-10-31。分支：`codex/mana-field-nodes`。版本：0.19.0 / Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21。

## 交付

完成魔力水晶、普通/深层矿石、天然地脉、人工节点、独立维度魔力场和环境汲取符文。采矿→装入水晶→节点释放→场扩散→法阵汲取→元素转换→真实施法的链路已接通。天然地脉储量有限，人工节点拆装保存余额；满场、满缓存和满节点不会继续消费不能接纳的资源。

法杖常规提示为三行，高级提示保留部件名，重复的原版属性段隐藏但真实近战属性保留。魔力HUD数值压缩，绘制页左下提示与停供状态精简。底环绘制修正透明混合，底环/蓝环不透明度分别为82/255与150/255。

玩法数值、配方、场机制、保存协议和当前限制见 [魔力场与节点](魔力场与节点.md)。本任务没有修改Godot运行代码或1.20.1工程。

初次截图发现降低PNG alpha仍得到实心底环，追查为旧的直接blit路径未启用透明混合。更换为带混合状态的RenderType后重新截图确认，正式包包含修正后的路径。首次资源重载遮罩覆盖截图的问题已在测试器中等待重载完成后修正。

## 复现

在1.21.1目录执行：

```powershell
./tools/build.ps1 -Tasks build,runGameTestServer,runClient -FieldSmoke -Mirror -Offline
./tools/build.ps1 -Tasks runClient -EditorSmoke -Mirror -Offline
```

在工作区根目录执行 `./tools/run_tests.ps1`。客户端验证器只在显式开关启用时加入测试源集，使用 `build/field-smoke` 的新世界，未操作正式玩家存档。

安装包：`../releases/elemental-circuits-1.21.1-0.19.0.jar`，1,107,148字节。

SHA-256：`429c2ba6e4cde261f13702512edd62bc05c0d7838003afa2fc315e9d1c9d2f71`。
