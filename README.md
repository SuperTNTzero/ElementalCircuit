# Elemental Circuits

Elemental Circuits is a Minecraft magic mod about designing spells as programmable circuits. Place runes on a hexagonal plate, connect mana and signal paths, and turn the result into a wand spell, an inscribed piece of equipment, or a fixed magical device.

## What you can build

- Combine elemental conversion, casting methods, shapes, and on-hit effects instead of choosing from a fixed spell list.
- Control spells with gates, counters, clocks, storage, and redstone-sensitive runes.
- Assemble three-part wands, switch between circuits with a selection wheel, and trigger circuits engraved on robes and rings.
- Draw mana from natural and artificial nodes, connect fixed circuits with mana dust, and inspect their connections through a gold monocle.
- Use earth magic and container runes to dismantle, place, and collect materials; use contact casting with separate force, constraint, and interaction effects.
- Store designs in blueprint notebooks and import custom casting and impact animations through local `.ecfx` packages.

The mod uses a deep-blue crystal and brass visual style, with 3D equipment, animated books, elemental spell effects, and spatial casting sounds. Player-facing content supports English and Simplified Chinese.

## Install

The current development version is **0.55.2**, for **Minecraft 1.21.1**, **NeoForge 21.1.265**, and **Java 21**.

1. Install NeoForge in a Minecraft 1.21.1 instance.
2. Add [Elemental Circuits 0.55.2](releases/elemental-circuits-1.21.1-0.55.2.jar) and [Curios API 9.5.1+1.21.1](releases/dependencies/curios-neoforge-9.5.1+1.21.1.jar) to `mods/` on both client and server.
3. Optionally install Patchouli **1.21.1-93-NEOFORGE** for the searchable in-game guide. The guide also works without it.

Start with the Circuit Field Guide, crafted from a book, blue dye, and a gold nugget. See the [1.21.1 guide](1.21.1/README.md) for engraving, controls, configuration, and building from source. Checksums and package requirements are in [releases](releases/README.md).

This is a development mod. Back up worlds before updating; compatibility with old development save and blueprint formats is not guaranteed.
