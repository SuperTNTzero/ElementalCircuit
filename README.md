# 元素法阵 · Minecraft 版本总目录

原 Godot 游戏仍位于工作区的 `game/`。Minecraft 模组及其版本工程、交付物已归拢在本目录。

| 目录 | 用途 |
|---|---|
| `1.20.1/` | Java 17 / NeoForge 47.1.106 的完整既有工程、设计文档与历史验证记录；当前版本0.14.0 |
| `1.21.1/` | Java 21 / NeoForge 21.1.265 的独立迁移工程；当前版本0.49.0 |
| `releases/` | 按 Minecraft 与模组版本命名的安装包及校验清单 |
| `tooling/` | 本机构建工具和缓存，被 Git 忽略；不属于模组发布内容 |

推荐安装包：[elemental-circuits-1.21.1-0.49.0.jar](releases/elemental-circuits-1.21.1-0.49.0.jar)。基板独立耐久、安全承载128/512/1280，达到四倍承载量时熔毁；保留法杖与设计，在法阵工作台消耗同材质基板修复。见 [基板承载与熔断](1.21.1/docs/systems/基板承载与熔断.md)。手札提供双语指南；可选安装Patchouli启用宝典目录和配方页。 新版增加15种[魔法附魔](1.21.1/docs/systems/魔法附魔.md)，含按实际修复量扣魔的魔力维修。

每个 Minecraft 版本单独构建、单独安装，选择与游戏版本对应的 JAR。不要在同一个实例同时安装两个版本。1.20.1 的原项目内容与构建缓存一并保留，源码没有因整理而被覆盖；历史日志中的旧绝对路径仅代表当时的运行位置。

新版构建与迁移范围见 [1.21.1说明](1.21.1/README.md)，既有玩法操作见 [1.20.1说明](1.20.1/README.md)。蓝图文本码继续作为跨版本分享设计的入口；Minecraft 世界升级和模组内部蓝图读取是不同过程，具体兼容验收见新版迁移报告。

当前任务分支 `codex/magic-enchantments`。未暂存、提交、合并、打 tag 或推送。
