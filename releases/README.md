选择对应游戏版本，在客户端与服务器的 `mods` 目录安装同一个JAR。无需额外玩法模组。完整校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)，机器可读信息见 [manifest.json](manifest.json)。

新版源码及运行说明位于 [1.21.1工程](../1.21.1/README.md)，迁移和测试证据位于 [迁移报告](../1.21.1/docs/1.21.1迁移报告.md)。旧工程完整保留于 `../1.20.1/`。整张真实旧世界升级仍需要在备份副本上验收。

0.16.0加入分层施法特效、元素冲击、成功伤害反馈及强化音效，预览和配置见 [施法表现与打击反馈](../1.21.1/docs/施法表现与打击反馈.md)。同一实例只保留一个版本的本模组JAR。

0.17.0更新界面、像素资源与玩家文本，详情及预览见 [界面与美术整理](../1.21.1/docs/界面与美术整理.md)。

0.18.0增加27种三维法杖组合与按部件速度计算的独立施法CD，见 [三维法杖与施法冷却](../1.21.1/docs/三维法杖与施法冷却.md)。

0.18.1将CD改为准星蓝色圆环，魔力条采用黄铜边框和粗体蓝字，见 [HUD说明](../1.21.1/docs/准星冷却环与魔力条.md)。

0.19.0新增有限魔力场、水晶矿物、天然/人工节点和环境汲取符文，清理文本并提高冷却环透明度，见 [玩法与机制](../1.21.1/docs/魔力场与节点.md)。新矿物只在新区块生成；两端统一使用新协议版本。

0.20.0更新工作台模型与贴图，并将刻印和组杖收拢到对应工作台；持三种基板与刻阵台互动可制作固定法阵。两端统一更新，操作与源文件见 [工作台说明](../1.21.1/docs/工作台模型与交互.md)。

0.20.1修复贴图拉伸和缩小时串色、桌面/工具/法杖穿插、悬浮水晶碰撞及双格模型边界，见 [修复与验证](../1.21.1/docs/工作台贴图与穿模修复.md)。因碰撞数据更新，客户端与服务端都要更新本版（协议1.21.1-6）。

0.21.0更新三种六角固定阵盘、简化工作台选框，基板完成刻印后才成为固定法阵；说明与证据见 [固定法阵刻印与外观](../1.21.1/docs/固定法阵刻印与外观.md)。

0.21.1重绘三种阵盘的高密度纹理，模型和制作规则保持0.21.0规则，见 [贴图细化](../1.21.1/docs/法阵贴图细化.md)。

0.22.0新增六种实际体积形状与静态符印，网络协议1.21.1-8要求两端一起更新，用法与验证见 [扩展形状符文](../1.21.1/docs/扩展形状符文.md)。
